## ✨ Fitur

- 🏠 **Home**: pengenalan brand dan keunggulan bahan yang lebih sehat
- 📖 **About Us**: visi, misi, dan program sosial Cokobell
- 🎂 **Products**: katalog kue bertema, cookies, dan kopi
- 🛒 **Order via WhatsApp**: form pesanan yang langsung terkirim ke WhatsApp
- 🖼️ **Gallery**: tim, proses produksi, event, dan pelanggan
- 📍 **Location**: foto toko dan peta Google Maps
- 📱 **Responsive**: nyaman dibuka di HP, tablet, dan desktop

## 🛠️ Teknologi

| Bagian | Teknologi |
|--------|-----------|
| Struktur | HTML5 |
| Styling | CSS3 (Flexbox & Grid) |
| Interaksi | JavaScript (Vanilla) |
| Hosting | GitHub Pages / Netlify |

Tanpa framework dan tanpa dependensi, jadi ringan dan mudah dipelajari.

## 🚀 Menjalankan di Lokal

```bash
git clone https://github.com/USERNAME/cokobell-company-profile.git
cd cokobell-company-profile
npx serve
```

Atau cukup buka `index.html` di browser, atau pakai ekstensi **Live Server** di VS Code.
